# Maurisha Fannani Saragih — Personal Portfolio

A dark, minimalist, responsive portfolio built with Next.js App Router and static export.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Deploy free to Vercel

1. Create a GitHub account and a new repository.
2. Upload/push all files in this folder to the repository.
3. Sign in to Vercel with GitHub and import the repository.
4. Keep the default build settings and deploy.
5. Vercel will provide a public `*.vercel.app` URL you can put in your Instagram bio.

The project uses `output: "export"` in `next.config.ts`, so it can also be hosted as a static site on compatible hosts.

## Personalize before publishing

- Update the About Me copy to reflect your own story.
- Replace the experience placeholder with your actual roles, company names, dates, and contributions.
- Replace project category cards with real project titles, screenshots, outcomes, and links.
- Confirm the skills list matches your actual skills.
- Add your email address in `app/page.tsx` to replace `href="mailto:"`.
- Add real achievements/certifications before presenting them as facts.

The current Experience, Projects, Skills, and Achievements sections intentionally use starter content/placeholders where personal details have not been provided.
